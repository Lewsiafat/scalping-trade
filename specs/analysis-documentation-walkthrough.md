## 技術細節
- 交易者文件採**流程導向**結構，從按下分析按鈕開始，沿著數據流程逐步展開每個環節
- 開發者文件採**模組導向**結構，按類別/功能區塊組織，方便查閱與維護
- 兩份文件都使用 Mermaid 圖表（流程圖、類別圖、狀態圖、時序圖）輔助說明
- 交易者文件完全透明公開所有計分權重、門檻數值與公式，讓使用者可自行驗證判斷
- 開發者文件的「設計決策」章節解釋關鍵設計的 why（如 Structure 權重 0.40 最高、R:R < 0.7 拒絕等）
- 開發者文件的「擴展指南」提供新增指標/權重/端點/SMC 元件/i18n 的具體步驟
- 多人使用情境在交易者文件簡述，在開發者文件詳細說明並發模型與全域狀態影響
