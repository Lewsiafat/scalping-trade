# 修正信號引擎多空非對稱 Bug

- **分支:** `fix/signal-symmetry-bug`
- **日期:** 2026-03-17

## 描述
信號引擎中存在 2 處多空條件不對稱的邏輯缺陷，導致系統偏向產生多頭信號、幾乎不出現賣出信號。

### Bug 1: MTF 一致性加/扣分不對稱
- **位置:** `calc_trend_score()` L1398-1401
- **現狀:** MTF 與 BOS 方向一致時 +25，不一致時僅 -10
- **修正:** 不一致改為 -25，使加/扣分對稱

### Bug 2: RSI 背離門檻不對稱
- **位置:** `calc_momentum_score()` L1573-1576
- **現狀:** 看多背離要求 RSI > 35，看空背離要求 RSI < 65（不對稱於中點 50）
- **修正:** 改為 RSI > 30 / RSI < 70（對稱於中點 50，距離各 20）

## 任務清單
- [x] 修正 `calc_trend_score()` MTF 不一致扣分 -10 → -25
- [x] 修正 `calc_momentum_score()` RSI 背離門檻 35/65 → 30/70
